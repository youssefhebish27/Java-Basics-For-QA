# 🚀 QA Automation Engine

Welcome to my first Java project! I built this mini-program to practice Java basics for Software Testing and Automation. 

## 🎯 Project Goal
This project acts like a simple test runner. It executes test cases, checks the results, and prints a final **QA Execution Report** with a success percentage.

## 🛠️ What I Learned & Used
In this project, I applied core Java concepts and linked them to QA logic:
* **Variables:** To store test data (String, int, double, boolean).
* **Methods:** To create reusable test steps (like `verifyPayment`).
* **If/Else Conditions:** To make Assertions (Checking if a test Passed or Failed).
* **Loops (For):** To simulate a retry mechanism (e.g., waiting for a server connection).
